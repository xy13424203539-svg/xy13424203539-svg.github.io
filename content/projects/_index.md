实验室的在研内容按技术组组织，分水下机器人与微纳制造及智能传感两个方向。

### 水下机器人

| 方向 | 内容 |
| --- | --- |
| 仿生鱼 | 仿生鱼整机结构、驱动机构与水下运动控制 |
| 水下机器人 | 水下机器人平台、沉浮控制与水下作业 |
| 海陆空机器人 | 跨介质运动机构与海陆空平台 |

### 微纳制造与智能传感

| 方向 | 内容 |
| --- | --- |
| 微纳 3D 打印 | 微纳尺度结构成型与打印工艺 |
| 静电纺丝 | 纳米纤维制备与电流体动力喷印 |
| 传感器 | 传感器设计与信号采集处理 |
