---
title: 奖励机制
summary: 只设奖励、不设扣分，按获奖等级分档发放。
date: 2026-11-11
type: page
---

实验室只设奖励，不设扣分与惩罚条款。奖励以竞赛获奖为主要依据，按获奖等级分档发放，奖金上限为 1000 元。

### 奖金标准

| 级别 | 等级 | 奖金（元） |
| --- | --- | --- |
| 校级 | 三等奖 | 100 |
| 校级 | 二等奖 | 200 |
| 校级 | 一等奖 | 300 |
| 省级 | 三等奖 | 300 |
| 省级 | 二等奖 | 450 |
| 省级 | 一等奖 | 600 |
| 国家级 | 三等奖 | 600 |
| 国家级 | 二等奖 | 800 |
| 国家级 | 一等奖 | 1000 |
| 国家级 | 特等奖 | 1000 |

国家级一等奖与特等奖同为上限 1000 元；特等奖在金额之外另计入实验室年度成果名录，并在站点成果页单列。

### 发放规则

- **凭据**：以主办方盖章的获奖证书为准，证书扫描件由组长归档，作为发放依据。
- **不叠加**：同一成果在校级、省级、国家级重复获奖的，按最高一级计发一次。
- **团队奖分配**：团队奖项由组长提出分配方案，报指导教师确认后发放，分配方案留存备查。
- **署名认定**：以证书上的完成人排序为准，未列入证书者不计发。
- **与学校奖励并行**：学校层面另发的竞赛奖励不受本表限制，可同时获得。
- **发放时点**：每学期末统一结算一次。

### 说明

本表为实验室内部执行标准，金额以实验室经费实际列支为准。标准如需调整，由指导教师提出、经实验室确认后在站内更新，不追溯已发放月份。
