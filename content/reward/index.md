实验室只设奖励，不设扣分与惩罚条款。奖励以竞赛获奖为主要依据，按获奖级别与等级分档发放。**表内金额为一个获奖团队的总额，不是每人的金额。**

### 奖金标准

| 级别 | 等级 | 奖金（元 / 团队） |
| --- | --- | --- |
| 校级 | 三等奖 | 100 |
| 校级 | 二等奖 | 200 |
| 校级 | 一等奖 | 300 |
| 省级 | 三等奖 | 300 |
| 省级 | 二等奖 | 450 |
| 省级 | 一等奖 | 600 |
| 国家级 | 三等奖 | 1000 |
| 国家级 | 二等奖 | 2000 |
| 国家级 | 一等奖 | 3000 |
| 国家级 | 特等奖 | 3000 |

国家级一等奖与特等奖同为 3000 元；特等奖在金额之外另计入实验室年度成果名录，并在站点成果页单列。

### 发放规则

- **团队总额**：表内金额发放给该获奖团队，由团队成员按贡献分配，不按人数平摊，也不按人头发放。
- **可叠加**：同一赛事在校级、省级、国家级分别获奖的，各级分别计发，可叠加领取。
- **凭据**：以主办方盖章的获奖证书为准，证书扫描件由负责人归档，作为发放依据。
- **分配方案**：团队奖项由负责人提出分配方案，报指导教师确认后发放，分配方案留存备查。
- **署名认定**：以证书上的完成人排序为准，未列入证书者不参与分配。
- **与学校奖励并行**：学校层面另发的竞赛奖励不受本表限制，可同时获得。
- **发放时点**：每学期末统一结算一次。

### 说明

本表为实验室内部执行标准，金额以实验室经费实际列支为准。标准如需调整，由指导教师提出、经实验室确认后在站内更新，不追溯已发放月份。
