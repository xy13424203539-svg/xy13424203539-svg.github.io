以下条款参照教育部《高等学校实验室安全规范》及高校实验室通行做法制定，适用于本实验室全部成员。

### 一、准入与安全培训

| 编号 | 条款 |
| --- | --- |
| 1.1 | 新成员进入实验室前须完成安全培训与设备操作培训，由所在组负责人带教，考核合格后方可独立操作设备。 |
| 1.2 | 首次使用某台设备，由设备负责人讲解操作规程与应急处置，首次操作须有人在场。 |
| 1.3 | 涉及加热、高压、高速旋转、强电的实验，须两人以上在场，不得单独操作。 |
| 1.4 | 出现异响、冒烟、漏液、报警等异常，立即断电停机、挂牌停用并报告实验室负责人，不得带故障继续操作。 |

### 二、设备使用与登记

| 编号 | 条款 |
| --- | --- |
| 2.1 | 使用 3D 打印机、静电纺丝机、超声波清洗机、压缩机、烘干机等设备，须在设备旁的使用记录本上登记日期、起止时间、用途、设备状态与使用人。 |
| 2.2 | 一机一册，记录本定点放置，不得带出、撕页或事后补记。 |
| 2.3 | 开机前检查设备状态，实验结束按要求停机、断电、清洁、归位。 |
| 2.4 | 设备故障立即停用并挂停用标识，报设备负责人联系维修，不得自行拆修。 |
| 2.5 | 未经许可不得将设备、配件、工具带出实验室；外借须登记并约定归还时间。 |

### 三、耗材与材料管理

| 编号 | 条款 |
| --- | --- |
| 3.1 | 耗材统一登记领用，写明名称、规格、数量、领用人与用途。 |
| 3.2 | 贵重耗材与稀缺材料单独存放，领用须经所在组负责人同意。 |
| 3.3 | 采购由使用人提出申请，写明用途、数量与预算，报实验室负责人审批后统一采购，不得私自向厂商下单。 |
| 3.4 | 化学品、胶黏剂、清洗剂按性质分类存放，容器标签完整清晰，用后归位。 |
| 3.5 | 废料、废液、废电池分类收集，不得倒入水槽或普通垃圾桶。 |

### 四、课题分工与进度汇报

| 编号 | 条款 |
| --- | --- |
| 4.1 | 每个课题设课题负责人一名，负责分工、排期与对外汇报，成员分工写在项目页。 |
| 4.2 | 每周固定组会，各课题汇报本周进展、下周计划、卡点与需要支持的事项。 |
| 4.3 | 连续两周无实质进展的课题，由负责人说明原因并调整分工或换人。 |
| 4.4 | 关键节点（方案评审、样机联调、参赛提交）前设内部预审，由非本课题成员交叉检查。 |
| 4.5 | 对外参赛、申报、答辩的名单与排序，以实际贡献为依据，由课题负责人提出、实验室负责人确认。 |

### 五、数据与图纸归档

| 编号 | 条款 |
| --- | --- |
| 5.1 | 设计文件、代码、测试数据与照片按“课题／日期／版本”命名，存放于实验室共享目录，不得只留在个人电脑。 |
| 5.2 | 每完成一版样机或一轮试验，同步归档一次，含三维模型、工程图、程序、原始数据与照片。 |
| 5.3 | 归档保留可编辑源文件，不以仅导出的格式替代。 |
| 5.4 | 参赛、专利、论文所用的数据，须能在归档目录中追溯到原始记录。 |
| 5.5 | 成员离组前完成本人在研课题的资料移交，由课题负责人签收。 |

### 六、对外署名与成果归属

| 编号 | 条款 |
| --- | --- |
| 6.1 | 以实验室名义参赛、申报、发表，须经实验室负责人同意，不得以个人名义使用实验室成果。 |
| 6.2 | 论文、专利、软著的署名与排序按实际贡献确定，投稿或申报前完成确认。 |
| 6.3 | 对外宣传、答辩、路演使用实验室设备照片、样机与数据，须经负责人同意。 |
| 6.4 | 成果计入个人页与成果荣誉页，以证书、受理通知书等原始材料为准。 |

### 七、退出与交接

| 编号 | 条款 |
| --- | --- |
| 7.1 | 退出前完成设备归还、耗材清点、资料归档与在研任务交接。 |
| 7.2 | 交接须有书面清单，由接手人与课题负责人双方签字。 |
| 7.3 | 借用的设备、工具、门禁权限在退出当日归还或注销。 |
| 7.4 | 未完成交接的，暂不办理离组手续。 |

条款一经启用不再改编号，修订以追加新条款的方式进行，旧条款标注失效日期。
